1. What is fx?

Every card script is plain Lua. Before the game calls your hook, it injects a table named fx — the effects host API. You do not require it. Think of it as the toolkit the tavern hands your card for one pulse. 

-- hooks: score
function on_score(fx)
  -- fx is already here. Read the board, then write damage.
  fx.add_to_me(100)
end
  • SCORE (on_score) — after hop/streak are on the cards; add effect damage or deal direct HP.
  • CLASH (on_clash) — after both sides finished SCORE; block incoming from mirrored slots.
  • BUILD never runs scripts (no spoilers of OK/BREAK or damage).

Indices are 1-based (Lua). Damage uses the locked ×100 scale (so 100 = one hop unit on the tally).

2. What “line” and “slot” mean

During an attack you play up to 5 cards onto your line (order matters for hops). Each played card sits in a slot numbered 1 … #cards.

  • fx.my_slot() — which seat this card is pulsing in right now.
  • fx.line_cards() — the array of played cards (L[1], L[2], …).
  • fx.my_line() — the whole Line table (.cards, .capacity, .empty, links, break).
  • fx.my_chain() — only the unbroken valid-prefix segment that contains this card (empty if you sit past a BREAK).
  • fx.empty_slots() — unused capacity (5 − #played), not leftover hand cards.
-- Dense form you may still see in older notes:
local line, i = fx.self.line, fx.self.slot

-- Clearer equivalent:
local i = fx.my_slot()
local line = fx.my_line()
local L = fx.line_cards()  -- same as line.cards

Mirrored slots: in CLASH, Shield looks at the enemy card in the same slot index (fx.enemy_at_my_slot()). Empty enemy seat → nothing to block.

4. Thunderer — walkthrough

Goal: if this card sits in any seat of an S → K → S triple on the played line, add +100 effect.

-- hooks: score
-- Neighbor windows still need Lua indexing (see “What stays dense”).
function on_score(fx)
  local i = fx.my_slot()
  local L = fx.line_cards()
  local function is_sks(a, b, c)
    return a and b and c and a.type == "S" and b.type == "K" and c.type == "S"
  end
  if is_sks(L[i - 1], L[i], L[i + 1])
     or is_sks(L[i], L[i + 1], L[i + 2])
     or is_sks(L[i - 2], L[i - 1], L[i]) then
    fx.add_to_me(100)
  end
end
  1. i = my slot. L = played cards array.
  2. is_sks checks three neighbors are present and typed S, K, S.
  3. Three windows cover “I’m the middle K”, “I’m the left S”, and “I’m the right S”.
  4. fx.add_to_me(100) bumps this card’s effect channel (not a direct HP hit).

In the editor, pick Thunderer — mock line S @ S expects +100 effect on the middle K.

5. Golem — walkthrough

Goal: +50 effect per G sharing this card’s scored chain (valid-prefix segment).

function on_score(fx)
  local n = 0
  for _, c in ipairs(fx.my_chain()) do
    if c.type == "G" then n = n + 1 end
  end
  fx.add_to_me(n * 50)
end
  1. fx.my_chain() is not the whole line — only the unbroken segment containing self.
  2. Past a BREAK, chain is empty → Golem adds 0.
  3. Mock G G @ → three G in chain → +150.

6. Sprinter — walkthrough

Goal: +30 effect per changer (K or S) on the full played line.

function on_score(fx)
  local n = 0
  for _, c in ipairs(fx.line_cards()) do
    if c.type == "K" or c.type == "S" then n = n + 1 end
  end
  fx.add_to_me(n * 30)
end
  1. Uses line_cards(), not my_chain() — cards after a break still count if they were played.
  2. Does not count unplayed hand cards.
  3. Mock K @ S → two changers → +60.

7. Burnt Offering — walkthrough

Goal: deal 100 × empty line slots straight to enemy HP.

function on_score(fx)
  local empty = fx.empty_slots()
  if empty > 0 then
    fx.deal_to_enemy(empty * 100)
  end
end
  1. empty_slots() = capacity − played count (line empties, not hand leftovers).
  2. deal_to_enemy is direct HP — bypasses mirrored slot clash / Shield unless a future API blocks directs.
  3. Mock 2-card line on capacity 5 → 3 empties → 300 to enemy.

8. Shield — walkthrough

Goal: in CLASH, block half of the enemy card sitting in my mirrored slot.

-- hooks: clash
function on_clash(fx)
  local foe = fx.enemy_at_my_slot()
  if not foe then return end
  local half = math.floor(fx.outgoing(foe) / 2)
  fx.block_me(half)
end
  1. Must declare clash in the hooks line — SCORE writers cannot call block_me.
  2. fx.outgoing(foe) sums hop+streak+effect on that enemy card (frozen after SCORE).
  3. block_me reduces what that enemy slot deals to you on APPLY.
  4. PvC with an empty enemy line → foe is nil → Shield no-ops (expected until dual lines / PvP).

9. Common mistakes

  • 0-based indexing — Lua arrays are 1-based. L[0] is always nil.
  • Reading enemy outgoing in SCORE — forbidden / meaningless for clash design. Use on_clash.
  • Calling add_to_me in CLASH — SCORE-only write; host logs and ignores.
  • Calling block_me in SCORE — CLASH-only; host logs and ignores.
  • Confusing line empties with hand leftovers — Burnt Offering uses line capacity, hand is 6.
  • Using my_chain when you meant the full line — Sprinter wants line_cards().
  • Forgetting the hooks header — editor Hooks field / -- hooks: score must match the functions you define.
  • Writing channel "mult" — v0 writers may only use "effect" (sugar already picks effect).
  • Expecting Shield to eat Burnt Offering — directs bypass slots by design.

10. What can’t be simpler without losing power

Sugar removes dense paths, not control flow. These still need real Lua — wrapping them in a host helper would either be a one-off card API or hide the rules you need to tweak:

  • Thunderer neighbor windows — three overlapping S-K-S seats. A fx.in_sks() would be Thunderer-only product logic inside the host, not a general verb.
  • Custom patterns — “two Airs with a Gap”, type sequences, counting with early break — keep for / if in the script.
  • Targeting another card — add_to_me is the pulsing card only; buffing a neighbor still uses fx.add(L[i-1], n, "effect").
  • Channel filters — fx.outgoing(card, { skip = "streak" }) stays explicit for rare pierce-shield designs.
  • Hand / draw / discard vision — pile helpers stay side-argument form (fx.unplayed(fx.self)) because enemy faces are gated by reveal rules.
